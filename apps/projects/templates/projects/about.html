{% trans "02 · What DevNepal is — and is not" %}

{% trans "What DevNepal verifies" %}

  • {% trans "Government projects have an accountable ministry publisher, maintainer, suitability review, and contribution guidance before publication." %}
  • {% trans "Community projects identify their owner, terms, repository, and route for questions before they open for collaboration." %}
  • {% trans "Accepted contributions retain a visible evidence and decision trail; raw activity is not treated as impact by itself." %}

{% trans "What DevNepal does not promise" %}

  • {% trans "A listing is not an employment offer, procurement commitment, or guarantee that a contribution will be merged." %}
  • {% trans "DevNepal is not a code host; branches, issues, pull requests, and CI remain with the project’s repository." %}
  • {% trans "Community projects are not government endorsements simply because they are listed here." %}
