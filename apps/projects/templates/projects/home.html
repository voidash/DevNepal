{% trans "What DevNepal verifies" %}

  • {% trans "A government project names its officer and its maintainer, and passes a suitability review, before it is published." %}
  • {% trans "A community project names its owner, its terms and where to ask questions before it opens." %}
  • {% trans "An accepted contribution keeps a public record of its evidence and the decision. Activity on its own is not counted." %}

{% trans "What DevNepal does not promise" %}

  • {% trans "A listing is not an employment offer, a procurement commitment, or a guarantee that your work will be accepted." %}
  • {% trans "DevNepal does not host code. Branches, issues, pull requests and CI stay with the project’s repository." %}
  • {% trans "A first-response time is how quickly a ministry aims to reply, not a promise about the outcome." %}
